# PracticePR

这是一个供读者练习 GitHub 协作流程的公开仓库。你可以从这里选择一个任务，提交修改，由维护者亲自审阅。

不需要先会写代码。翻译文档、补充说明、添加一份练习记录，都可以作为第一次贡献。

## 从这里开始

1. 在 [Issues](https://github.com/LING71671/PracticePR/issues) 中选择一个尚未有人处理的任务，阅读背景和验收条件。
2. 在该 Issue 下留言认领，等待维护者确认，避免重复劳动。新增自己的练习记录时，先创建一条属于自己的 Issue。
3. 阅读 [贡献指南](CONTRIBUTING.md)，Fork 仓库，并为这个任务创建一个分支。
4. 完成修改，检查差异，再提交 Pull Request（简称 PR）。在描述中写明做了什么、如何检查，并使用 `Closes #任务编号` 关联 Issue。
5. 查看自动检查和维护者的审阅意见。在同一个分支上继续修改，新的提交会更新原 PR。
6. 维护者确认后合并 PR，关联的 Issue 自动关闭。之后同步自己的 Fork，并删除已经合并的练习分支。

每个 PR 尽量只完成一项任务。请保留其他人的文件和已有内容。

## 可以练习什么

| 任务 | 练习内容 |
| --- | --- |
| 添加自己的练习记录 | Issue、Fork、分支、提交、PR、根据审阅意见修改 |
| 翻译 README | 翻译、保留原文、语言导航、Markdown 链接 |
| 补充常见问题 | 描述问题、解释操作、验证说明 |
| 补充术语表 | 理解概念、举例、控制修改范围 |

以 [Issue 列表](https://github.com/LING71671/PracticePR/issues) 中的任务状态为准。也可以先提 Issue，说明你发现的问题和打算如何改进。

## 审阅与合并

PR 由维护者本人审阅并手动合并。自动检查通过后，仍需等待人工审阅；本仓库不自动合并，也不承诺固定处理时间。

审阅会关注任务是否完成、内容是否准确、修改是否超出范围，以及是否影响已有内容。收到修改建议后，可以在 PR 下讨论具体原因，再更新原分支。

## 公开内容

所有 Issue、PR 和提交记录都会公开。练习记录只需要 GitHub 用户名和学习内容，请勿提交密码、密钥、联系方式或其他私人资料。
